# Lab 8 - Controlled Staging Release

## 1. Release Information

- Project: laravel-request-system
- Laravel Version: 12.69.2
- Starting Commit: 9ead5f0
- Release Branch: feature/lab8-staging-release
- Target Environment: Staging

## 2. Pre-Deployment Checklist

- [ ] Verify the application version.
- [ ] Verify the Git commit.
- [ ] Review the release changes.
- [ ] Prepare the release notes.
- [ ] Confirm the staging environment.
- [ ] Obtain deployment approval.

## 3. Deployment Checklist

- [ ] Deploy the approved release.
- [ ] Check application availability.
- [ ] Test student login.
- [ ] Test request creation.
- [ ] Test retrieving a saved request.
- [ ] Test admin status updates.
- [ ] Verify students cannot update admin-only statuses.

## 4. Rollback Checklist

- [ ] Identify the failed release.
- [ ] Record the failed test.
- [ ] Roll back to the known-good version.
- [ ] Verify application recovery.
- [ ] Confirm saved data remains available.

## 5. Final Documentation

- [ ] Record deployment results.
- [ ] Record smoke test results.
- [ ] Record rollback results.
- [ ] Update the project documentation.
